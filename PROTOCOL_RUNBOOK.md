# 🚀 Ранбук: Оффлайн-управление подсветкой Ajazz AK820 Max HE

Этот документ описывает результаты реверс-инжиниринга HID-протокола клавиатуры Ajazz AK820 Max HE для работы в оффлайн-режиме (без веб-драйверов).

---

## 📋 1. Спецификация устройства (Hardware ID)

Для работы с клавиатурой через библиотеку hid используются следующие параметры:
- Vendor ID (VID): 0x0c45
- Product ID (PID): 0x80b1
- Интерфейсы: У клавиатуры 4 HID-интерфейса (1-9:1.0 — 1-9:1.3). Для надежности пакет отправляется сразу на все доступные пути.

---

## 📦 2. Структура HID-пакета (35 байт полезной нагрузки)

Пакет передается с ведущим нулевым байтом Report ID (0x00), за которым следует полезная нагрузка из 64 байт.

- Индекс 0: 0xaa (Маркер начала пакета)
- Индекс 1: 0x23 (Длина пакета - 35 байт)
- Индекс 2: 0x10 (Код команды: Управление подсветкой)
- Индексы 3-7: 0x00 (Служебные заполнители)
- Индекс 8: 1 или 0 (Питание подсветки: 1 = Вкл, 0 = Выкл)
- Индекс 9: 0xff (Красный цвет: 0x00 – 0xff)
- Индекс 10: 0x00 (Зеленый цвет: 0x00 – 0xff)
- Индекс 11: 0x00 (Синий цвет: 0x00 – 0xff)
- Индекс 12: 0xff (Общая яркость / служебный байт)
- Индексы 13-16: 0x00 (Дополнительные параметры)
- Индекс 17: 0x05 (Подтип команды)
- Индекс 18: 0x03 (Дополнительный флаг)
- Индексы 19-21: 0x00 (Нули)
- Индексы 22-23: 0xaa 0x55 (Маркеры конца пакета)
- Индексы 24-63: 0x00 (Заполнитель до 64 байт)

---

## 🛠️ 3. Итоговый скрипт управления (ajazz_light.py)

Инструмент командной строки (CLI) для управления подсветкой:

import argparse
import hid

VENDOR_ID = 0x0c45
PRODUCT_ID = 0x80b1

def set_color(power, r, g, b):
    packet = [
        0xaa, 0x23, 0x10, 0x00, 0x00, 0x00, 0x01, 0x00,
        power, r, g, b, 0xff,
        0x00, 0x00, 0x00, 0x00, 0x05, 0x03, 0x00, 0x00, 0x00,
        0xaa, 0x55
    ] + [0x00] * 40

    for device_dict in hid.enumerate(VENDOR_ID, PRODUCT_ID):
        try:
            device = hid.device()
            device.open_path(device_dict['path'])
            device.write([0x00] + packet)
            device.close()
        except Exception:
            pass
    print(f"Цвет установлен: Power={power}, R={r:02x}, G={g:02x}, B={b:02x}")

if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Управление подсветкой Ajazz AK820 Max HE")
    parser.add_argument("-p", "--power", type=int, default=1, choices=[0, 1], help="1 - вкл, 0 - выкл")
    parser.add_argument("-r", "--red", type=lambda x: int(x, 0), default=0xff, help="Красный (0-255)")
    parser.add_argument("-g", "--green", type=lambda x: int(x, 0), default=0x00, help="Зеленый (0-255)")
    parser.add_argument("-b", "--blue", type=lambda x: int(x, 0), default=0x00, help="Синий (0-255)")

    args = parser.parse_args()
    set_color(args.power, args.red, args.green, args.blue)

## ⚠️ 4. Подводные камни и «Грабли»

1. Ошибка PEP 668 на Arch Linux (externally-managed-environment):
   - Проблема: Прямой вызов `pip install hid` блокируется системой.
   - Решение: Всегда использовать виртуальное окружение (`python -m venv ajazz-env`).

2. Ловушка с sudo и виртуальным окружением:
   - Проблема: Запуск через `sudo python` игнорирует `venv` и вызывает `ModuleNotFoundError`.
   - Решение: Использовать полный путь к интерпретатору внутри окружения: `sudo ./ajazz-env/bin/python ...`.

3. Множественные HID-интерфейсы:
   - Проблема: Стандартный `device.open()` открывает случайный эндпоинт.
   - Решение: Перебирать все устройства через `hid.enumerate()` и открывать их через `open_path()`.

4. Захват устройства браузером:
   - Проблема: Открытая вкладка с оригинальным веб-драйвером удерживает устройство.
   - Решение: Закрывать вкладки перед запуском локальных скриптов.

## 5. Настройка магнитных свитчей (Hall Effect / Rapid Trigger)

Настройка параметров срабатывания выполняется через команду `0x38` (длина заголовка/маркера `0x27`). В отличие от подсветки, контроллер не принимает настройки одним коротким пакетом: требуется инициализация и последовательная запись всех 18 секторов памяти клавиш.

### Алгоритм транзакции при записи свитчей
1. **Пакет инициализации:** отправляется один пакет `0xaa, 0x27, 0x10, 0xf0, 0x03, 0x00, 0x01, 0x00` + 56 нулей (итого 64 байта + ведущий `0x00` Report ID). Пауза `0.02` сек.
2. **Пакеты данных (18 штук):** последовательно отправляются 18 пакетов с командой `0x38`.
   - Байты `3` и `4` содержат смещение (offset) в формате `little-endian`, начиная с `0x0000` и увеличиваясь каждый шаг на `0x0038` (56 байт = 7 клавиш по 8 байт) до `0x03b8`.
   - Байты `5..7`: `0x00, 0x00, 0x00`.
   - Байты `8..63`: 7 блоков по 8 байт с настройками конкретных клавиш.
   - После каждого пакета выдерживается пауза `0.01` сек.

### Структура 8-байтного блока одной клавиши
Все значения дистанций кодируются как целое число сотых долей миллиметра (`round(mm * 100)`) в формате `little-endian` (младший байт первый). Например: `0.20 мм` -> `20` (`0x14, 0x00`), `1.50 мм` -> `150` (`0x96, 0x00`).

- **Байт 0:** `0x03` — заголовок / тип блока клавиши.
- **Байт 1:** Режим Full Distance Fast Trigger:
  - `0x01` — включен (Rapid Trigger работает по всей длине хода).
  - `0x00` — выключен (Rapid Trigger включается только после прохождения точки срабатывания).
- **Байты 2..3:** `Trigger Distance` (глубина срабатывания, от `0.10` до `4.00` мм).
- **Байты 4..5:** `Press Sensitivity` (чувствительность повторного нажатия в режиме Fast Trigger). Если Fast Trigger выключен, передается `0x00, 0x00`.
- **Байты 6..7:** `Release Sensitivity` (чувствительность сброса/отпускания в режиме Fast Trigger). Если Fast Trigger выключен, передается `0x00, 0x00`.

### Итоговый скрипт управления свитчами (ajazz_rapid.py)

import argparse
import hid
import time

VENDOR_ID = 0x0c45
PRODUCT_ID = 0x80b1

def set_switch_params(trigger_mm: float, press_mm: float, release_mm: float, enable_ft: bool, full_ft: bool):
    t_val = int(round(trigger_mm * 100))
    p_val = int(round(press_mm * 100)) if enable_ft else 0
    r_val = int(round(release_mm * 100)) if enable_ft else 0
    full_flag = 0x01 if (enable_ft and full_ft) else 0x00

    block = [
        0x03, full_flag,
        t_val & 0xff, (t_val >> 8) & 0xff,
        p_val & 0xff, (p_val >> 8) & 0xff,
        r_val & 0xff, (r_val >> 8) & 0xff,
    ]

    offsets = [
        (0x00, 0x00), (0x38, 0x00), (0x70, 0x00), (0xa8, 0x00), (0xe0, 0x00),
        (0x18, 0x01), (0x50, 0x01), (0x88, 0x01), (0xc0, 0x01), (0xf8, 0x01),
        (0x30, 0x02), (0x68, 0x02), (0xa0, 0x02), (0xd8, 0x02), (0x10, 0x03),
        (0x48, 0x03), (0x80, 0x03), (0xb8, 0x03)
    ]

    devices = hid.enumerate(VENDOR_ID, PRODUCT_ID)
    if not devices:
        print("Ошибка: Клавиатура не найдена!")
        return

    for device_dict in devices:
        try:
            device = hid.device()
            device.open_path(device_dict['path'])

            init_packet = [0xaa, 0x27, 0x10, 0xf0, 0x03, 0x00, 0x01, 0x00] + [0x00] * 56
            device.write([0x00] + init_packet)
            time.sleep(0.02)

            for off_low, off_high in offsets:
                packet = [0xaa, 0x27, 0x38, off_low, off_high, 0x00, 0x00, 0x00] + block * 7
                device.write([0x00] + packet[:64])
                time.sleep(0.01)

            device.close()
        except Exception:
            pass

    print(f"Применено: Trigger={trigger_mm}mm, FT={'ON' if enable_ft else 'OFF'}, Full_FT={'ON' if full_flag else 'OFF'}, Press={press_mm if enable_ft else 0}mm, Release={release_mm if enable_ft else 0}mm")

if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Управление магнитными свитчами Ajazz AK820 Max HE")
    parser.add_argument("--trigger", type=float, default=0.20, help="Trigger Distance в мм")
    parser.add_argument("--press", type=float, default=0.30, help="Press Sensitivity в мм")
    parser.add_argument("--release", type=float, default=0.16, help="Release Sensitivity в мм")
    parser.add_argument("--ft", type=int, default=1, choices=[0, 1], help="Fast Trigger: 1 (вкл) или 0 (выкл)")
    parser.add_argument("--full", type=int, default=0, choices=[0, 1], help="Full Distance FT: 1 (вкл) или 0 (выкл)")
    args = parser.parse_args()

    set_switch_params(args.trigger, args.press, args.release, bool(args.ft), bool(args.full))

## 6. Дополнительные «Грабли» (Магнитные свитчи)

5. Отправка одиночного пакета 0x38 не работает:
   - Проблема: Если отправить только один пакет со смещением 0x0000, контроллер клавиатуры игнорирует изменения или обновляет только первые несколько клавиш.
   - Решение: Всегда отправлять всю цепочку из 18 пакетов со смещениями от 0x0000 до 0x03b8 (шаг 0x38).
6. Отсутствие пакета инициализации:
   - Проблема: Без предварительной отправки сервисного пакета (0xaa, 0x27, 0x10, 0xf0...) настройки свитчей могут не примениться к контроллеру.
   - Решение: Всегда предварять серию команд 0x38 пакетом инициализации и выдерживать паузы (10-20 мс) между записями.
7. Сброс Fast Trigger при выключении:
   - Особенность: В протоколе Ajazz нет отдельного бита "вкл/выкл Fast Trigger". Режим считается выключенным, когда байты Press Sensitivity и Release Sensitivity равны нулю (0x0000).

## 7. Калибровка датчиков Холла (Switch Calibration)

Калибровка выполняется аппаратно внутри контроллера клавиатуры. Софт лишь переключает состояния клавиатуры с помощью коротких 64-байтных HID-пакетов (передаются с ведущим нулевым байтом Report ID `0x00`).

### Команды калибровки
- **Старт калибровки:** `0xaa, 0x64` + 62 нуля. Переводит клавиатуру в режим записи максимальной глубины нажатия свитчей. Обычный ввод клавиш в ОС на время калибровки полностью отключается.
- **Сброс калибровки (Clear Calibration):** `0xaa, 0x0f, 0x05` + 61 нуль. Очищает текущие накопленные калибровочные данные.
- **Полный заводской сброс (Factory Hard Reset):** `0xaa, 0x0f, 0xff` + 61 нуль. Выполняет аппаратный сброс всех настроек контроллера к заводским значениям с перезагрузкой USB-устройства.
- **Сохранение и выход (Save Calibration):** `0xaa, 0x65` + 62 нуля. Записывает новые значения датчиков Холла в постоянную память клавиатуры и возвращает её в штатный рабочий режим.

### Итоговый скрипт калибровки (ajazz_calib.py)

import argparse
import hid
import time

VENDOR_ID = 0x0c45
PRODUCT_ID = 0x80b1

def send_cmd(cmd_bytes):
    packet = cmd_bytes + [0x00] * (64 - len(cmd_bytes))
    devices = hid.enumerate(VENDOR_ID, PRODUCT_ID)
    if not devices:
        print("Ошибка: Клавиатура не найдена!")
        return False
    for d in devices:
        try:
            dev = hid.device()
            dev.open_path(d['path'])
            dev.write([0x00] + packet)
            dev.close()
        except Exception:
            pass
    return True

def run_calibration(duration: int, clear_first: bool):
    print("Переводим клавиатуру в режим калибровки...")
    if not send_cmd([0xaa, 0x64]):
        return
    time.sleep(0.2)

    if clear_first:
        print("Сбрасываем старую калибровку (Clear)...")
        send_cmd([0xaa, 0x0f, 0x05])
        time.sleep(0.2)

    print(f"\n>>> КАЛИБРОВКА АКТИВНА ({duration} сек.) <<<")
    print("Клавиатура временно отключена от ОС. Прожмите до упора нужные клавиши!")
    
    for remaining in range(duration, 0, -1):
        print(f"Осталось секунд: {remaining:2d}...", end="\r")
        time.sleep(1)

    print("\nСохраняем калибровку и возвращаем клавиатуру в рабочий режим...")
    send_cmd([0xaa, 0x65])
    print("Готово! Клавиатура снова работает в штатном режиме.")

if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Оффлайн-калибровка Ajazz AK820 Max HE")
    parser.add_argument("-t", "--time", type=int, default=15, help="Время на калибровку в секундах (по умолчанию 15)")
    parser.add_argument("--clear", action="store_true", help="Сбросить текущую калибровку перед началом")
    args = parser.parse_args()

    run_calibration(args.time, args.clear)

## 9. Настройка мертвых зон (Advanced Settings / Dead Zone)

В отличие от индивидуальных параметров срабатывания клавиш, настройки мертвых зон (Dead Zone) передаются одним 64-байтным пакетом (с ведущим нулевым байтом Report ID `0x00`) без предварительной инициализации и без разбиения на 18 секторов.

### Структура пакета Dead Zone
- **Байты 0..2:** `0xaa, 0x21, 0x38` — заголовок команды.
- **Байты 3..15:** `0x00, 0x00, 0x00, 0x01, 0x00, 0x00, 0x00, 0x00, 0x05, 0x00, 0x06, 0x00, 0x00` — служебные константы.
- **Байт 16:** `Top Dead Zone` — верхняя мертвая зона в сотых долях миллиметра (`round(mm * 100)`, например `0.37 мм` -> `37` -> `0x25`).
- **Байт 17:** `Bottom Dead Zone` — нижняя мертвая зона в сотых долях миллиметра (`round(mm * 100)`, например `0.36 мм` -> `36` -> `0x24`).
- **Байт 18:** `0x00` — разделитель.
- **Байт 19:** `Dead Zone Enable` — флаг активности (`0x01` = включено, `0x00` = выключено).
- **Байты 20..21:** `0x00, 0x00` — нули.
- **Байт 22:** `0x01` — завершающий флаг.
- **Байты 23..63:** `0x00` — заполнение буфера до 64 байт.

### Итоговый скрипт управления мертвыми зонами (ajazz_deadzone.py)

import argparse
import hid

VENDOR_ID = 0x0c45
PRODUCT_ID = 0x80b1

def set_deadzone(top_mm: float, bottom_mm: float, enable: bool):
    top_val = int(round(top_mm * 100)) & 0xff
    bot_val = int(round(bottom_mm * 100)) & 0xff
    en_flag = 0x01 if enable else 0x00

    packet = [
        0xaa, 0x21, 0x38, 0x00, 0x00, 0x00, 0x01, 0x00,
        0x00, 0x00, 0x00, 0x05, 0x00, 0x06, 0x00, 0x00,
        top_val, bot_val, 0x00, en_flag, 0x00, 0x00, 0x01
    ]
    packet += [0x00] * (64 - len(packet))

    devices = hid.enumerate(VENDOR_ID, PRODUCT_ID)
    if not devices:
        print("Ошибка: Клавиатура не найдена!")
        return

    for d in devices:
        try:
            dev = hid.device()
            dev.open_path(d['path'])
            dev.write([0x00] + packet)
            dev.close()
        except Exception:
            pass

    print(f"Dead Zone: {'ON' if enable else 'OFF'}, Top={top_mm}mm (0x{top_val:02x}), Bottom={bottom_mm}mm (0x{bot_val:02x})")

if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Настройка Dead Zone для Ajazz AK820 Max HE")
    parser.add_argument("--top", type=float, default=0.30, help="Top Dead Zone в мм (по умолчанию 0.30)")
    parser.add_argument("--bottom", type=float, default=0.30, help="Bottom Dead Zone в мм (по умолчанию 0.30)")
    parser.add_argument("--enable", type=int, default=1, choices=[0, 1], help="1 — вкл, 0 — выкл")
    args = parser.parse_args()

    set_deadzone(args.top, args.bottom, bool(args.enable))

## 10. Архитектура поклавишной настройки (Матрица 126 слотов)

Чекбоксы групп в веб-драйвере (`Select All`, `WASD`, `Numeric keys`, `Arrow keys`) не имеют отдельных команд в HID-протоколе и обрабатываются исключительно на стороне UI.

- **Принцип работы:** 18 пакетов команды `0x38` (по 7 блоков из 8 байт в каждом) формируют линейный массив из **126 слотов** (`index 0..125`), жестко привязанных к физическим позициям клавиш на плате.
- **Проектирование будущего приложения:**
  - В памяти приложения должен храниться массив конфигурации `key_configs[126]`, где каждый элемент описывает свой 8-байтный блок (`full_ft`, `trigger`, `press`, `release`).
  - При выборе группы клавиш (например, только `WASD` или произвольное выделение на виртуальной раскладке) приложение меняет объекты только по соответствующим индексам в `key_configs`, после чего сериализует весь массив в 18 пакетов и отправляет на клавиатуру.
  - Для получения полной карты раскладки (какой индекс из `0..125` какой физической клавише соответствует) достаточно в веб-драйвере выбрать нужную клавишу/группу, задать уникальное значение `Trigger Distance` и найти изменившиеся слоты в дампе 18 пакетов.
- **Вспомогательные элементы UI (`Record` и `Cancel`):**
  - `Record` — чисто клиентская функция (не отправляет HID-пакеты). При активации приложение слушает обычные системные события нажатия клавиш (`keydown`) и автоматически добавляет нажатые физические клавиши в текущее выделение на схеме.
  - `Cancel` — сбрасывает текущее выделение клавиш в интерфейсе без отправки команд на клавиатуру.

## 11. Переназначение клавиш и слои (Custom Keys)

Переназначение клавиш записывается в память клавиатуры в виде таблицы из 128 слотов (512 байт), где каждой клавише отводится **4 байта**.

### Команды слоев
- **`0x22`** (`0xaa, 0x22, ...`) — запись раскладки основного слоя (**Normal Layer**).
- **`0x26`** (`0xaa, 0x26, ...`) — запись раскладки функционального слоя (**Fn Layer**).

### Структура транзакции (10 пакетов)
1. **9 пакетов данных:** заголовок `0xaa, [0x22 или 0x26], 0x38, off_low, off_high, 0x00, 0x00, 0x00` + 56 байт данных (14 клавиш по 4 байта). Смещения идут от `0x0000` до `0x01c0` с шагом `0x38`.
2. **10-й финальный пакет:** `0xaa, [0x22 или 0x26], 0x08, 0xf8, 0x01, 0x00, 0x01, 0x00` + последние 8 байт таблицы (2 слота по 4 байта) + нули до 64 байт.

### Формат 4-байтного слота клавиши
- **Слот по умолчанию (без переназначения):** `0x00, 0x00, 0x00, 0x00`.
- **Обычная клавиша (Basic / Extended Characters):** `0x02, mod_mask, hid_keycode, 0x00`
  - `0x02` — тип действия (клавиша клавиатуры).
  - `mod_mask` — битовая маска модификаторов (`0x00` — без модификаторов, `0x01` — LCtrl, `0x02` — LShift, `0x04` — LAlt, `0x08` — LWin).
  - `hid_keycode` — стандартный USB HID Usage ID (например, `0x04` = A, `0x05` = B, `0x29` = Esc, `0x2a` = Backspace).
  - `0x00` — резервный байт.

## 12. Продвинутые функции свитчей: Rappy Snappy (Advanced Keys)

Функция **Rappy Snappy (RS)** связывает две любые клавиши (кроме `Fn`) и активирует ту, которая нажата глубже. В прошивке она реализуется одновременным изменением двух таблиц: параметров свитчей (`0x38`) и таблицы раскладки (`0x22`).

### Алгоритм активации Rappy Snappy
1. **Таблица параметров свитчей (18 пакетов `0xaa, 0x27, 0x38...`):**
   - В 8-байтных слотах обеих выбранных клавиш первый байт меняется с `0x03` на `0x00` (отключается стандартный триггер в пользу режима RS).
   - В байтах `2..3` (little-endian) записывается порог срабатывания RS в сотых долях миллиметра (например, `1.46 мм` -> `146` -> `0x92, 0x00`).
   - Пример блока для клавиши в режиме RS: `0x00, 0x00, 0x92, 0x00, 0x00, 0x00, 0x00, 0x00`.
2. **Таблица раскладки (10 пакетов `0xaa, 0x22...`):**
   - В 4-байтные слоты обеих клавиш записывается идентичный дескриптор связи:
     `0x0c, 0x00, hid_key1, hid_key2`
   - `0x0c` — код типа действия **Rappy Snappy**.
   - `hid_key1`, `hid_key2` — стандартные USB HID Usage ID первой и второй клавиши (например, для пары `A` + `D`: `0x04` и `0x07`).
   - При удалении привязки в слоты раскладки записываются нули (`0x00, 0x00, 0x00, 0x00`).

### Известные индексы клавиш в матрице (0..125)
- **Слот 0:** `Esc` (HID `0x29`)
- **Слот 49:** `A` (HID `0x04`) — 8-й пакет (`offset 0x0188`), 1-й блок.
- **Слот 50:** `S` (HID `0x16`) — 8-й пакет (`offset 0x0188`), 2-й блок (по расположению в ряду).
- **Слот 51:** `D` (HID `0x07`) — 8-й пакет (`offset 0x0188`), 3-й блок.

## 13. Продвинутые функции свитчей: SOCD (Advanced Keys)

Режим **SOCD** (обработка одновременного нажатия противоположных клавиш) использует ту же двухэтапную схему записи, что и Rappy Snappy, но поддерживает полноценную настройку Rapid Trigger и режимов приоритета.

### Формат дескриптора SOCD в таблице раскладки (`0x22`)
В 4-байтные слоты обеих выбранных клавиш записывается:
`0x0b, pattern_mask, hid_key1, hid_key2`
- **`0x0b`** — код типа действия **SOCD**.
- **`pattern_mask`** — код/маска режима приоритета (Behavioral Pattern):
  - `0x01` — Last Input Priority (приоритет последнего нажатия)
  - `0x02` — Absolute Key 1 Priority
  - `0x03` — Absolute Key 2 Priority
  - `0x04` — Anti-Ghosting Mode (нейтрализация при одновременном нажатии)
- **`hid_key1`, `hid_key2`** — USB HID коды обеих клавиш.

### Формат блока свитчей (`0x38`) при SOCD
В 8-байтные слоты выбранных клавиш записывается:
`0x00, full_ft, trigger_low, trigger_high, press_low, press_high, release_low, release_high`
- Первый байт равен `0x00` (стандартный триггер отключен).
- Остальные байты кодируют `Full Distance FT`, `Trigger Distance`, `Press Sensitivity` и `Release Sensitivity` в сотых долях миллиметра.

---

## 14. Динамический ход клавиш: DKS (Advanced Keys)

Профили **DKS** хранятся в отдельной таблице памяти (1024 байта), записываемой командой **`0x28`** (18 пакетов по 56 байт + 19-й финальный пакет `0xaa, 0x28, 0x10, 0xf0, 0x03, 0x00, 0x01, 0x00...` с остатком 16 байт).

- **Привязка в таблице раскладки (`0x22`):** в 4-байтный слот клавиши пишется `0x08, profile_index, 0x00, 0x00` (`0x08` = код DKS, `profile_index` = `0..39`).
- **Структура 16-байтного профиля DKS (`0x28`):**
  - Байты `0..3`: 4 глубины срабатывания в десятых долях мм (`round(mm * 10)`, например `1.6 мм` -> `0x10`, `3.0 мм` -> `0x1e`).
  - Байты `4..7`: 4 USB HID кода клавиш.
  - Байты `8..15`: 4 двухбайтовые битовые маски активных точек срабатывания.

---

## 15. Двойное действие по удержанию: Mod-Tap / MT (Advanced Keys)

Режим **Dual Effect Click (MT)** не использует отдельных таблиц и записывается напрямую в 4-байтный слот раскладки (`0xaa, 0x22`):

`0x09, hold_hid, click_hid, hold_time_10ms`
- **`0x09`** — код типа действия **Mod-Tap (MT)**.
- **`hold_hid`** — USB HID код клавиши при удержании.
- **`click_hid`** — USB HID код клавиши при коротком нажатии.
- **`hold_time_10ms`** — порог времени удержания в десятках миллисекунд (`round(ms / 10)`, например `560 мс` -> `56` -> `0x38`).

---

## 16. Залипание по нажатию: Toggle Switch / TGL (Advanced Keys)

Режим **Toggle Switch (TGL)** (клик включает/выключает постоянное зажатие клавиши) записывается напрямую в 4-байтный слот раскладки (`0xaa, 0x22`):

`0x0a, hid_keycode, 0x00, 0x00`
- **`0x0a`** — код типа действия **Toggle Switch (TGL)**.
- **`hid_keycode`** — стандартный USB HID код зажимаемой клавиши (например, `0x27` = `0`).

### Сводная таблица кодов Advanced Keys в слотах раскладки
- `0x02` — обычная клавиша (`[0x02, mod_mask, hid_keycode, 0x00]`)
- `0x08` — **DKS** (`[0x08, dks_profile_idx, 0x00, 0x00]`)
- `0x09` — **Mod-Tap (MT)** (`[0x09, hold_hid, click_hid, hold_time_10ms]`)
- `0x0a` — **Toggle (TGL)** (`[0x0a, hid_keycode, 0x00, 0x00]`)
- `0x0b` — **SOCD** (`[0x0b, pattern_mask, hid_key1, hid_key2]`)
- `0x0c` — **Rappy Snappy (RS)** (`[0x0c, 0x00, hid_key1, hid_key2]`)

## 17. Системные настройки клавиатуры (Keyboard Settings / Пакет 0x21)

Пакет `0xaa, 0x21, 0x38` является единым конфигурационным блоком системных параметров клавиатуры и объединяет мертвые зоны, частоту опроса и адаптивную калибровку:

- **Байт 13 — Частота опроса (Return Rate):**
  - `0x03` — 1000 Гц (1K)
  - `0x05` — 4000 Гц (4K)
  - `0x06` — 8000 Гц (8K)
- **Байт 16:** `Top Dead Zone` (`round(mm * 100)`).
- **Байт 17:** `Bottom Dead Zone` (`round(mm * 100)`).
- **Байт 19:** `Dead Zone Enable` (`0x01` = вкл, `0x00` = выкл).
- **Байт 22:** `Adaptive Dynamic Calibration` (`0x01` = вкл, `0x00` = выкл).

*Важно:* Поскольку все эти настройки хранятся в одном пакете `0x21`, при изменении частоты опроса или адаптивной калибровки необходимо передавать актуальные значения мертвых зон в байтах `16..19`, чтобы они не затерлись нулями.
- **Байт 6:** `Stability Mode` (`0x01` = вкл, `0x00` = выкл).
- *Совет для DevTools:* Для перехвата команд, вызывающих перезагрузку страницы (например, `Reset all keyboard settings`), необходимо включить опцию **Preserve log** в настройках консоли браузера.

## 18. Макросы (Shortcut Command / Команда 0x25)

Запись макросов выполняется командой **`0x25`** в два этапа: таблица указателей (`0x0000..0x018F`) и тело макроса (`0x0190+`).

### Структура транзакции макроса
1. **Таблица указателей (8 пакетов):**
   - Первый пакет (`offset 0x0000`) содержит смещение начала первого макроса `M1`: `0x90, 0x01` (`0x0190` = 400).
   - Следующие 7 пакетов (`0x0038`, `0x0070`, `0x00a8`, `0x00e0`, `0x0118`, `0x0150`, `0x0188`) заполняют нулями остаток таблицы указателей.
2. **Пакет тела макроса (`offset 0x0190`):**
   - Заголовок: `0xaa, 0x25, payload_len, 0x90, 0x01, 0x00, 0x01, 0x00`.
   - Заголовок макроса (4 байта): `steps_count_x2, 0x00, 0x00, 0x00`.
   - События макроса (по 4 байта на каждое действие): `delay_low, delay_high, hid_keycode, event_flag`
     - `delay_low, delay_high` — задержка в миллисекундах (`little-endian`).
     - `hid_keycode` — стандартный USB HID Usage ID клавиши.
     - `event_flag` — тип события: `0xb0` = нажатие (`Key Down`), `0x30` = отпускание (`Key Up`).
3. **Привязка макроса к клавише (`0x22`):**
   - В 4-байтный слот выбранной клавиши записывается дескриптор: `0x06, macro_index, loop_mode, 0x00` (`0x06` = код действия **Macro**, `macro_index` = `0` для `M1`).

## 19. Полная структура пакета подсветки (Lighting Settings / 0x23)

Уточнённая побайтовая карта пакета `0xaa, 0x23, 0x10`:
- **Байт 8:** Режим подсветки (`0x00` = выкл, `0x01` = Static, `0x04` = Starry Sky, `0x0b` = Flowing; эффекты пронумерованы последовательно от `0x01` до `0x13`).
- **Байты 9..11:** `R, G, B` (`0x00..0xff`).
- **Байт 12:** `0xff` (мастер-уровень).
- **Байт 16:** `Color mode` (`0x00` = Monochrome, `0x01` = Rainbow RGB).
- **Байт 17:** `Lighting Brightness` (`0x00..0x05`).
- **Байт 18:** `Lighting Speed` (`0x01..0x05`).
- **Байт 19:** `Lighting Direction` (`0x00` = влево, `0x01` = вправо).
- **Байты 22..23:** `0xaa, 0x55` (сигнатура конца пакета).

## 21. Справочник команд единого оффлайн-драйвера (`ajazz.py`)

Все расшифрованные функции объединены в единый CLI-инструмент `ajazz.py`:
- **`light`** — цвет RGB, яркость (`0..5`), скорость (`1..5`), направление (`0/1`), радужный режим (`--rgb-mode 1`) и любой из 19 эффектов (`-m starry`, `-m flowing` или hex-код).
- **`switch`** — глубина срабатывания (`--trigger`), чувствительность нажатия/отпускания (`--press`, `--release`), включение Rapid Trigger (`--ft`) и режим работы по всей длине хода (`--full`).
- **`deadzone`** — верхняя и нижняя мертвые зоны (`--top`, `--bottom`, `--enable`).
- **`calib`** — оффлайн-калибровка датчиков Холла по таймеру (`-t 15`) с опцией предварительного сброса (`--clear`).
- **`remap`** — переназначение клавиш на слоях `normal` (`0x22`) и `fn` (`0x26`) по индексу слота и USB HID-коду.
- **`rs`** — Rappy Snappy для любой пары клавиш (`--slot1`, `--hid1`, `--slot2`, `--hid2`, `--trigger`).
- **`socd`** — SOCD с выбором режима приоритета (`--pattern 1..4`) и независимым Rapid Trigger.
- **`dks`** — 4-уровневый динамический ход клавиши (`--depths`, `--keys`, `--mask1..4`).
- **`mt`** — Dual Effect Click / Mod-Tap (`--hold`, `--click`, `--time`).
- **`tgl`** — Toggle Switch / залипание по клику (`--keycode`).
- **`settings`** — частота опроса (`--rate 1k|4k|8k`), стабильность (`--stability`) и адаптивная калибровка (`--adaptive`).
- **`macro`** — запись последовательности нажатий/отпусканий с задержками (`--keys`, `--delay`) и привязка к клавише (`--slot`).

## 22. Выбор модели магнитного свитча (Selectable Axles)

Первый байт (индекс `0`) в 8-байтном блоке настроек клавиши (команда `0x38`) определяет профиль кривой Холла для установленной модели свитча:
- `0x01` — **Magnetic Rice Switch**
- `0x02` — **Magneto Shaft** (предположительно)
- `0x03` — **Magnetic Jade Pro**
- `0x00` — отключенный стандартный триггер (используется в режимах RS / SOCD) или пустой слот матрицы.

## 23. Телеметрия датчиков Холла в реальном времени (Калибровка / Input Report 0x55 0xfb)

После перевода клавиатуры в режим калибровки (`0xaa, 0x64`) контроллер начинает циклически отправлять на сервисный интерфейс **`IF 2`** (`usage_page >= 0xff00`) 64-байтные входящие пакеты телеметрии состояния каждого свитча:

`0x55, 0xfb, slot_idx, status_flag, top_low, top_high, bot_low, bot_high, cur_low, cur_high, ...`
- **Байты `0..1`:** `0x55, 0xfb` — сигнатура пакета телеметрии Холла.
- **Байт `2` (`slot_idx`):** физический индекс клавиши в матрице контроллера (`0..125`).
- **Байт `3` (`status_flag`):** флаг калибровки слота (`0x01` — не откалиброван / после `Clear`, `0x00` — нижняя точка записана).
- **Байты `4..5` (`top_adc`, little-endian):** опорное значение АЦП в состоянии покоя (верхняя точка, обычно `~2450–2600`, тепловой шум `±2` единицы).
- **Байты `6..7` (`bot_adc`, little-endian):** калибровочный минимум (нижний упор). В сброшенном состоянии установлен старший бит `0x80` (`0x84xx` / `0x85xx`), после нажатия до упора записывается реальный минимум (например, `0x05dc` = `1500`).
- **Байты `8..9` (`cur_adc`, little-endian):** текущее живое значение АЦП датчика Холла. В покое совпадает с `top_adc`, при нажатии клавиши до упора падает на `700–1100` единиц.
